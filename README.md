## The joke

> Our daily standup lasts 45 minutes, which is why we sit down for it now.

## About

A tiny TypeScript program (`main.ts`) that writes the joke — exactly one line, 72 characters — to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR` when the grader sets it). It validates the line first: 1–200 characters, at least one visible character, no line breaks.

Run it:

```sh
node main.ts
```
